# control

Central monitoring and control platform for ENG-MD-HUB apps.

- **Live dashboard:** https://eng-md-hub.github.io/control/ (owner only: password + two-step code)
- **Data:** the free Supabase project `readme-monitor`, protected by row-level security.
- **No build step:** one static `index.html` served by GitHub Pages.

The full design document lives in Claude Docs.
